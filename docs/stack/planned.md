# Planned platforms

Not supported today. Each entry says what exists and what is missing.

| Platform | Status | Today |
|---|---|---|
| macOS | Planned | Nothing runs on macOS. `install.sh` detects only Linux, WSL and Omarchy. The generated theme files for Alacritty, Kitty, Ghostty, Neovim, VS Code, bat and Starship are plain files you can copy by hand. |
| Windows (native, PowerShell) | Planned | Nothing runs natively. Use WSL ([wsl.md](wsl.md)). The Windows Terminal schemes (`umbra`, `umbra-void`, `umbra-lux`) work for WSL profiles. |

Other Planned items: Omarchy void and lux themes, Discord and Spotify themes, and more TUI apps.
